Create a world pair

Build two possible explanations for the same observations. Check what an intervention reveals, then export your pair to try in the laboratory.

1 · Create

Define the two worlds

Opening a file replaces this worksheet's draft after successful checks. Export your current pair first if you want to keep it. Only rules this probability form can preserve are reopened. Other valid pairs can still be used in the laboratory. Opening here does not open an investigation.

Each trial uses independent uniform random inputs. Chances change in steps of 12.5% (one eighth).

World 1

Set A first, then use A's state to set B's chance. Equal conditional chances mean A has no effect on B.

World 2

Set B first, then use B's state to set A's chance. Equal conditional chances mean B has no effect on A.

2 · Check

See what an intervention reveals

An intervention holds one lamp off or on, replacing its usual rule. Compare the resulting outcomes in both worlds.

A valid file is only the first check. For this kind of causal puzzle, the worlds must have exactly the same observational distribution and different distributions under the selected intervention. These are calculations for the entered rules. They do not establish a lesson's educational quality, and individual random trials can still look alike.

3 · Export and try

Take your pair into the laboratory

Check your current draft before exporting. After any edit, check it again so the results describe the pair you save.

Open laboratory (new tab)
  1. Export the world pair as a JSON file.
  2. In the laboratory, choose Open an authored world pair and select that file.
  3. Review it, then choose Open as a new investigation.
